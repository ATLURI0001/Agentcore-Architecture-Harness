# Contributing

Open an issue for a reproducible bug or proposed improvement. For security issues, follow [SECURITY.md](SECURITY.md).

Submit focused pull requests to [ATLURI0001/agentcore-architecture-harness](https://github.com/ATLURI0001/agentcore-architecture-harness). Describe the change, how you tested it, and any impact on IAM permissions or Terraform resources. Remove account IDs, credentials, and private deployment output from examples.

Contributors follow the [code of conduct](CODE_OF_CONDUCT.md). See [LICENSE](LICENSE) and [third-party notices](THIRD_PARTY_LICENSES.md) for licensing details.
